# Agency Engineering Standard

A reusable foundation for building reliable software with AI-assisted development tools.

## Purpose

This repository contains engineering instructions, quality standards, reusable workflows, and security practices for future agency projects.

## Principles

- Human-reviewed changes
- Small, verifiable implementation steps
- Automated testing and quality checks
- Secure handling of credentials and customer data
- Clear documentation and honest reporting of limitations

## Current Status

Initial setup. Automated checks, reusable workflows, and project templates will be added incrementally.

## Safety

Never commit API keys, passwords, access tokens, private customer data, or production secrets.
